
# powerbi-data-modelling

## Description

Educational Power BI project focused on data modeling and building relationships between tables.

## Objectives

* Understand fact and dimension tables.

* Create relationships between tables.

* Learn cardinality and cross-filter direction.

* Understand data granularity (grain).
* Practice building a structured data model in Power BI.
## Tools

* Microsoft Power BI Desktop
* Power Query

## Learning Source

This project was completed as part of my Power BI learning journey using a YouTube tutorial.
